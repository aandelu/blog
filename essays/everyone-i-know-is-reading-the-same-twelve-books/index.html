Everyone I know is reading the same twelve books

At some point in the last few years, the set of books it is possible to mention at dinner without explaining yourself shrank to about twelve. You know the ones. They have the same cover design, more or less, and the same blurb, and a surprising number of them are about a woman in her thirties moving to a coastal town.

I do not think this is because people read less. I think it is because recommendation has been centralised. The bookshop table, the podcast, the list, the other list that is a reaction to the first list: they all draw from the same reservoir, and the reservoir is small because it has to be. A recommendation only works if the person you give it to might actually read the thing.

The cure, if it is a cure, is to be boring about it. Read the long book nobody asked you about. Bring it up anyway. The worst that happens is a short silence, and the silence is where the interesting conversations used to start.
