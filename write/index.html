Publishing

Publishing commits the essay, and any pictures in it, to aandelu/blog on the main branch. GitHub then rebuilds the site. To do that from this browser, the editor needs a token from your GitHub account. It stays in this browser only.

  1. Open github.com/settings/personal-access-tokens/new.
  2. Under Repository access choose Only select repositories and pick aandelu/blog.
  3. Under Permissions, set Contents to Read and write. Leave everything else alone.
  4. Generate it, copy it, and paste it below.
